# studentbot5

StudentBot — это простой учебный чат-бот, созданный с помощью HTML, CSS и JavaScript.

## Цель проекта
Создать чат-бота для помощи студентам в изучении основ программирования и веб-разработки.

## Возможности
- отвечает на вопросы по HTML
- объясняет CSS
- рассказывает про JavaScript
- помогает с Python
- имеет простой интерфейс чата

## Использованные технологии
- HTML
- CSS
- JavaScript
- GitHub
- GitHub Pages

## Результат
В ходе работы был создан простой чат-бот для студентов, который отвечает на базовые учебные вопросы.
